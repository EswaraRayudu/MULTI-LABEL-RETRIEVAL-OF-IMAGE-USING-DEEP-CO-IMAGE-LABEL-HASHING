# Multi-Label Retrieval of Image Using Deep Co-Image-Label Hashing

## Project Overview
This project predicts multiple semantic labels for an uploaded image
using Deep Co-Image-Label Hashing (DCILH).

## Features
- Upload an image
- Generate image hash
- Predict image labels
- Display predicted labels
- Streamlit web interface

## Technologies Used
- Python
- TensorFlow / Keras
- OpenCV
- NumPy
- Streamlit
- Scikit-learn

## How It Works
Image
  ↓
Image Hash Generation
  ↓
Tokenization
  ↓
Deep Learning Model
  ↓
Label Prediction
  ↓
Predicted Labels
